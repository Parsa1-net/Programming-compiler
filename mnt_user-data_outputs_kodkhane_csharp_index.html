اجرای کامپایلر سی‌شارپ (C#) در کدخانه ◀

چطور از کامپایلر سی‌شارپ (C#) کدخانه استفاده کنم؟

  1. کد C# خود را در ویرایشگر بنویسید یا فایل را باز کنید؛ پیشنهاد خودکار کلمات با کلید Tab کامل می‌شود.
  2. دکمه‌ی «اجرا» یا کلیدهای Ctrl+Enter را بزنید.
  3. خروجی و خطاها را در ترمینال زیر ویرایشگر ببینید و در صورت نیاز از دستیار هوشمند کمک بگیرید.

امکانات کامپایلر سی‌شارپ (C#) کدخانه

  • برنامه‌های بدون کلاس و Main (top-level statements) خودکار به Program.Main تبدیل می‌شوند و شماره‌ی خطاها تغییر نمی‌کند.
  • Console.ReadLine قبل از اجرا ورودی می‌گیرد؛ Console.ReadKey در مرورگر پشتیبانی نمی‌شود.
  • LINQ، رکوردها، async/await و رشته‌های درون‌یابی‌شده با .NET جدید کار می‌کنند.
  • تاریخچه‌ی نسخه‌ها و بازگشت به کد قبلی، تم‌های روشن، تیره و متحرک، و ذخیره‌ی پروژه در حساب کاربری.

نمونه‌ی کد C#

using System;
using System.Linq;

class Program
{
    static void Main()
    {
        var numbers = new[] { 1, 2, 3, 4, 5 };
        Console.WriteLine("Sum of squares = " + numbers.Select(n => n * n).Sum());
    }
}
